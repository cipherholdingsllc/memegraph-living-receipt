# MemeGraph — The Replay Booth

A private-demo, human-first interface for MemeGraph.

**What this is:** a shareable preview of one synthetic example story. It shows how MemeGraph keeps a call frozen in time, replays the evidence that existed before and after the lock, and stamps the later result.

**What this is NOT:** a live experiment dashboard, a trading product, or a claim that MemeGraph predicts markets. The example data is made-up and explicitly labeled "Example story · made-up data."

**Receipts prove:** the saved record is internally consistent and the call was locked before the outcome.
**Receipts do NOT prove:** that the sources were true, that the history was unedited before saving, or that the predictor has skill.

Deployed as a static site. No external runtime requests. All fonts are self-hosted.
